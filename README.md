# devs.solutions

Sitio web para devs.solutions, una empresa joven dedicada al desarrollo de aplicaciones.

## Descripción

Este proyecto es un sitio web moderno y responsive para devs.solutions, una startup de desarrollo de aplicaciones fundada por dos socios. El diseño se inspira en tendencias modernas con un estilo oscuro, gradientes de color púrpura y rosa, y efectos visuales atractivos.

## Características

- Diseño moderno con tema oscuro y acentos de color
- Totalmente responsive para dispositivos móviles, tablets y escritorio
- Animaciones suaves al hacer scroll
- Sección de servicios con tarjetas interactivas
- Formulario de contacto funcional
- Menú de navegación intuitivo

## Tecnologías utilizadas

- HTML5
- CSS3 (con variables CSS, flexbox y grid)
- JavaScript vanilla
- Fuentes de Google Fonts
- Diseño responsive sin frameworks externos

## Estructura de archivos

```
/
├── index.html       # Estructura principal del sitio
├── styles.css       # Estilos CSS
├── script.js        # Funcionalidades JavaScript
└── README.md        # Este archivo
```

## Cómo iniciar

1. Clona este repositorio
2. Abre el archivo `index.html` en tu navegador preferido
3. ¡O simplemente visita [devs.solutions](https://devs.solutions)!

## Personalización

El sitio puede ser fácilmente personalizado modificando los colores principales en el archivo CSS:

```css
:root {
    --primary-color: #8a2be2; /* Color principal púrpura */
    --secondary-color: #ff3399; /* Color secundario rosa */
    --dark-bg: #0a0a1a; /* Fondo oscuro con tono azulado */
}
```
